# The Clock That Is the Sun

A giant clock face hangs alone in a near-black night sky — a huge warm disc, glowing amber-gold from within like a second sun. A tiny dark human silhouette stands on the long minute hand near its tip.

Entry for make.fun "Make the coolest art" (coolest-art-01). The program copies `art.jpg` to the output directory as `entry.png`, byte for byte.
